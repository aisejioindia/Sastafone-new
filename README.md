## 🛠️ Tech Stack

- **Framework**: React 19 (TypeScript)
- **Bundler & Dev Server**: Vite 8 with `@vitejs/plugin-react`
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`)
- **Icons**: Lucide React
- **Animations & Effects**: Motion & Canvas Confetti
- **Server**: Express proxy entry point

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/aisejioindia/sastafone.git
cd sastafone

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open `http://localhost:3000` in your browser.

### Build for Production

```bash
npm run build
```
